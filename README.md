# Simulador de dado de 6 faces

Aplicação estática simples para simular o lançamento de um dado comum de 6 faces.

## Como usar

1. Abra o arquivo `index.html` no navegador.
2. Clique em **Lançar dado**.
3. O resultado exibirá um valor aleatório entre 1 e 6.

## Arquivos

- `index.html`: estrutura da interface
- `style.css`: estilos da página
- `script.js`: lógica do sorteio e histórico de resultados
